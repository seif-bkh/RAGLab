   (المسار المتقاعد محظور سياسة — الفصل صريح في الشيفرة والتوثيق)، ولا أي تعديل
   على المدونة أو الفهرس.
2. **المدخلات:** `RAGLAB_GAP_ANALYSIS.md` §4.5 (المعجم علاج الضعف المعجمي؛ بذرة
   `best_variant_merge` المختبرة) + مدونة docs المعتمدة (مصطلحاتها مرجع
   المقابلات) + خطوط الأساس المعتمدة 3.1/3.2.
3. **الإجراءات:** وحدة `lexicon.py` بجدول بذور مُدار **كبيانات معلنة المصدر**
   (كل مدخل: الصيغة الواردة، الصيغة الرسمية، النوع، المصدر في المدونة)؛ دالة
   توسيع حتمية `expand_query(text) -> list[str]` تعيد الأصل + الصيغ المكافئة
   (بلا ازدواج، بترتيب ثابت)؛ ربط كخيار صريح في مسار الاسترجاع (`LEXICON_ENABLED`
   غير مفعل افتراضيًا) قبل بناء المتغيرات، مع تمرير كل الصيغ إلى التضمين وBM25
   ودمج نتائجها عبر `best_variant_merge` القائمة.
4. **المخرجات:** `lexicon.py` + جدول البذور (قابل للنقض مدخلًا مدخلًا) + اختبارات
   وحدة + قيد AGENTS §2.3.
5. **التحقق الآلي:** اختبارات (توسيع صفري حين لا مدخلات — سلوك مطابق للحالي
   حرفيًا؛ إدماج متعدد؛ ثبات الترتيب؛ عدم العبور إلى مسار الترجمة) + البوابة
   الكاملة EXIT=0.
6. **اختبار صاحب القرار:** مراجعة جدول البذور مدخلًا مدخلًا وحق النقض على أي
   مدخل؛ **جولة تأليف حالات عامي/مرادفات مستقلة لقياس الأثر قرار لاحق** (كما
   نص مخطط 2.4-أ: الفئات متاحة بلا حالات).
7. **معيار الانتقال:** التوسيع حتميًا محكومًا ومختبرًا والجدول معروضًا — القياس
   الرسمي على المجموعة موصول بجولة التأليف المعتمدة.
8. **التراجع:** جدول فارغ أو تعطيل الخيار = السلوك الحالي بالضبط.
