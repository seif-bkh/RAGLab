# معجم المرحلة 9

| المصطلح | المعنى في هذه الخطة |
|---|---|
| **سؤال اختبار / حالة** | إدخال محدد مع مقصد معلن وسلوك متوقع ودليل أو سبب غيابه؛ ليس مجرد صياغة استفسار |
| **الجواب الذهبي** | معيار مقبول للإجابة/التصرف ومصادره؛ لا يُعتمد قبل مراجعة الدليل والحالة |
| **نوع التصرف** | ما ينبغي للعميل فعله: جواب مباشر، تقدير مسند، استيضاح، جواب جزئي، امتناع مفسر، أو عدم قدرة على التنفيذ/الوصول |
| **قوة الدليل** | مدى مباشرة وكفاية المصدر؛ مستقلة عن نوع التصرف وعن ثقة النموذج المعلنة |
| **الاستيضاح للمستخدم** | سؤال متابعة ظاهر يطلب معلومة تؤثر في الجواب؛ ليس إعادة صياغة داخلية بواسطة النموذج |
| **الاستنطاق (Phase 8)** | تحليل داخلي للطلب وإعادة صياغته إلى سؤال تقني ثم إعادة تقييمه؛ لا يعني أن المستخدم استُوضح |
| **تقدير مسند** | تقريب مشتق من قيم أو قاعدة موثقة مع طريقة حساب وافتراضات وحدود معلنة |
| **تخمين حر** | تقدير لا يستند إلى دليل أو حساب قابل للإعادة؛ لا يُعد إجابة ناجحة في هذا القياس المصرفي |
| **الامتناع** | عدم تقديم جواب موضوعي غير مسند، مع بيان سبب مثل غياب المصدر أو بيانات شخصية أو معلومة آنية أو فعل غير مدعوم |
| **الموضوع/العنوان** | تسمية مصدرية من خريطة البنية؛ لا تفترض الخطة أن كل عنوان تصنيف دلالي جيد |
| **المسار البنيوي** | سلسلة الآباء من الوثيقة إلى الوحدة/المقطع، مع مصدر ومعرّف لكل عقدة |
| **وجه (facet)** | بعد تصنيف مستقل له قيم معلنة وقواعد إسناد قابلة للمراجعة؛ ليس مرادفًا للشجرة |
| **حفظ المقصد** | بقاء الإجابة متصلة بما قصده المستخدم، لا بما ولّدته إعادة صياغة قريبة فحسب |
| **خط أساس** | نتيجة مقيسة قبل أي تغيير، على نفس المجموعة والإعدادات المسجلة؛ لا يساوي رقمًا تاريخيًا من مجموعة أخرى |
